Save and reset

Run commands from the DigiStayBook project folder. The launcher saves every 30 seconds and on Ctrl+C. The next start loads the saved snapshot.

  • npm run test:local — build, start and seed if needed
  • npm run test:local:save — save now
  • npm run test:local:reset — replace all local Test data with the original accounts and examples
  • npm run test:local:workers — run due retry/deletion work now; production deadlines/backoff are preserved

After reset, sign out and back in. For fresh anonymous guest sessions, clear this site's browser data or use a private window. A reset affects only the known demo emulator project and buckets.

First walkthrough

  1. Sign in as Host; edit the cottage welcome and notes.
  2. Open the in-stay link; submit a clear memory with a photo.
  3. Edit and delete your own memory; check its disappearance and the local deletion job.
  4. Try review, safety and outage markers; verify each destination.
  5. Turn host review on; check that clear memories wait for approval.
  6. Submit private feedback and verify it never appears publicly.
  7. Sign in as Second host; verify ownership isolation.
  8. Sign in as Operations; open a safety case, release to host review or delete it.

Local tests do not verify deployed App Check, real MFA, Google classification, email receipt, Stripe payments or cloud recovery/deletion. No approval of draft legal text is recorded by this test setup.
