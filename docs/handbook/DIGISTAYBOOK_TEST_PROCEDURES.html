0 Before you start

Words used here

HostThe customer, who rents out a holiday home. You play the host in most checks.
GuestSomeone staying at the property. Guests don’t have accounts. You play one on your phone.
PropertyOne holiday home. A host can have several.
PlacardThe printed QR code the host leaves in the property.
In-stay wallThe page you get by scanning the placard. House info, host notes, and guests’ memories. Guests add memories here.
Public wallA shareable copy of the wall without the house info.
MemoryA guest’s message and/or photos.
DashboardThe host’s area after signing in.

Test site and live site

Test siteA practice copy. No real money or customers, so break whatever you like. Do all 38 checks.
Both sitesAlso repeated on the live site after release (18 checks).

Use Which checks on the left to show only the ones for your site.

On the live site

  • Only do checks marked Both sites, and skip steps marked Test site only.
  • Only use the Live test host account.
  • Never enter card details. Use the free code. If it asks for a card, stop.
  • If anything fails, stop and tell us straight away.

  • A computer.
  • A phone with a camera, plus a second phone or a private browser window.
  • A printer (or save as PDF and print later).
  • About 4½ hours over three sessions (below).
